Source code and technical details

Recognition

Recognition uses HOMR checkpoint 426, based on Polyphonic-TrOMR. The models and browser adapters use AGPL-3.0. The adapters were added on 17 September 2026. Their complete editable source is served with the app; no compilation is needed:

  • Image preprocessing, staff detection, and model inference
  • Recognized symbols to MusicXML
  • Worker, model loading, and caching
  • Model vocabulary and model file hashes
  • Photo and camera controls, score parsing, sheet display controls, and styles. Sheet playback controls use sampled grand piano audio.

The model protocol and vocabulary are from HOMR commit 5e51b434b3149286dae1448603527923b62ef9f2. The weights are from its ONNX checkpoint release, checkpoint identifier 426-b6fd20809a8dcaf10dfd39a4ca4f64c6f056e644.

ONNX Runtime Web 1.23.2 runs the models using WebAssembly (MIT license). OpenSheetMusicDisplay 2.1.2 draws the notation (BSD-3-Clause license).

Retained legacy chord-listening modules (not loaded by this app) use Basic Pitch, Copyright Spotify AB, under the Apache-2.0 license. The ICASSP 2022 ONNX model is pinned to commit fa5997af0a8210982619003269994a1be25eddf3; see its source and hash. Their browser adapters are audio processing and inference, the worker, and the live listener.
